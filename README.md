## Overview 
This assignment focused on a simulated Security Operations Center (SoC) scenario, in which the core object was to perform a deep inspection on a large-scale network capture to uncover and document an active security incident. Through the use of tools such as **Wireshark**, and custom **Scapy** Scripts, a PCAP file containing over a GB of network traffic was successfully analysed with key hosts, anomalous activity, and even active (and unused) attack vectors identified. 

Beyond just identifying the malicious activity, the report also provides a completely reproducible account of steps taken, as well as suggested mitigation strategies, and theoretical enhancements the attack could have made. 

## Relevant Skills  
- Through conducting **Deep Packet Inspections** I was able to extract key **Indicators of Comprises** and completely uncover attack timelines and methods. 
- Network Analysis: This assignment required extensive understanding about networking protocols, typical traffic patterns, and even network port specifics. All of which helped sift through a vast amount of data to differentiate benign operations from the malicious attacks.
- Assessed the scope of compromise to the network while additionally providing robust **Mitigation and Prevention** techniques.
